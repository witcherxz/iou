# IoU 0.1 Beta 3

This release adds custom payment schedules, so a debt no longer has to be split into equal monthly installments.

- New debt → **طريقة السداد** now offers **دفعة واحدة**, **أقساط شهرية** and **مخصص**. With **مخصص**, enter each payment's own amount and date — for example 1,000 in November, 2,500 in January and 1,500 in March.
- Add or delete payments (2–120). **+ إضافة دفعة** prefills the amount still unallocated and the month after the last payment. A running total shows any unallocated or excess amount, and saving stays disabled until the payments equal the debt exactly, every date is valid, no two payments share a date and none precedes the debt date.
- Payments are sorted by date when saved. The debt detail shows **جدول السداد · مخصص** for schedules that do not run in consecutive months.
- Custom schedules use the existing installment format: payments, forgiveness, reminders, editing, undo, backups and exports work unchanged. No data migration is needed.

Install `iou-0.1.0-beta.3.apk` over Beta 2. Android version code is `13`; the production identity, signing key and backup formats are unchanged.

TypeScript and the integrated checks passed, including 23 new schedule checks. A locally built, debug-signed QA package on the Android 16 emulator verified entry, excess/balanced totals, date sorting, the custom label, payment allocation across rows and persistence after reinstall. The production APK is built and signed by GitHub Actions. Font scale 2.0 and the user's phone have not been checked with this feature.
