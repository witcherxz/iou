# IoU 0.1 Alpha 3

The privacy lock now prompts for a fingerprint or face automatically when you open or return to the locked app, if supported biometrics are enabled.

- Strong enrolled biometrics remain enabled by default when setting up a new lock. Existing choices are preserved.
- Cancelling the prompt leaves the PIN available. The prompt does not repeatedly reopen while you are entering your PIN; you can retry biometrics with the button.
- Leaving the app locks it again. Returning starts a new biometric attempt, while the ledger stays hidden until authentication succeeds.
- PIN-only devices continue to show PIN entry. Existing records and PINs are preserved.

Install `iou-0.1.0-alpha.3.apk` over the previous alpha. This is a signed production build with Android version code `3`, the same package and signing key, and no demo ledger. Verify the download with the accompanying SHA-256 file.

Alpha 3 was installed over Alpha 2 on a Samsung S24 Ultra running Android 16. ADB observed the native biometric dialog appear automatically on launch and return from the background. Successful biometric entry, cancellation without repeated prompts, and subsequent PIN unlock passed on the phone. The manual Google Drive backup and distinct full/partial forgiveness features from Alpha 2 are included.
