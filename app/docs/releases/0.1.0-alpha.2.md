# IoU 0.1 Alpha 2

This update improves lock setup, makes the Google Drive backup option usable, and records debt forgiveness separately from payments.

- **Lock setup:** PIN derivation runs in a native worker on Android 8+ and iOS, preserving existing PINs and security settings. Unresponsive operations stop with an error and retry path; delayed results cannot unlock the ledger. Android 7 and Expo Go retain a responsive fallback.
- **Google Drive:** choose **Google Drive (يدوي)**, then share a readable backup to Drive or restore a downloaded file. Finish saving in Drive and check that the file appears there. This is manual backup; automatic Drive synchronization is not configured.
- **Forgiveness:** choose **إعفاء من الدين** when recording an entry, or open a debt's forgiveness action. Record a full or partial amount, actual date, and optional reason. Cash and forgiven amounts appear separately in history, installments, HTML reports, and CSV exports. Forgiveness supports editing, undo, cancellation and restoration.
- A debt partly paid and partly forgiven closes as **مغلق بسداد وإعفاء**. Full forgiveness shows **معفى بالكامل**. Closed debts no longer generate debt reminders.

## Update and data

Install `iou-0.1.0-alpha.2.apk` over Alpha 1. The production package and release signing key are unchanged; Android version code increases to `2`. Existing records and PINs are preserved. Ledger formats 1 and 2 migrate to format 3 without changing prior payments. Restore format 3 backups with this version or newer; older app versions do not understand forgiveness. Reports and CSVs remain readable without IoU.

The APK is a signed production build with debugging disabled and no demo ledger. Verify its download with the accompanying SHA-256 file.

## Device validation

Automated checks cover PIN compatibility, timeout handling, migration, forgiveness, recovery, exports, and reminders. ADB diagnostics on a Samsung S24 Ultra with Android 16 captured the original roughly two-minute JavaScript PIN calculation. Alpha 2 was installed successfully as an update, and the user confirmed that PIN unlock now works promptly. Diagnostics show the calculation on the native worker without the earlier sustained JavaScript load or errors. Biometric prompts, app-switcher privacy, native notification delivery, and Drive's save/upload completion still need device confirmation.
