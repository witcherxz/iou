# IoU 0.1 Alpha 10

Edit a person's name from the pencil button **تعديل اسم الشخص** on their page. The editor opens with the current name and provides **حفظ الاسم** and **إلغاء**. The new name appears throughout the app and in readable reports, exports and reminders while retaining the same person, debts, payments, exemptions and correction history.

Names are trimmed and limited to 100 characters. Empty names and names already used by another person are rejected; people are never merged. Keeping the same name creates no save or recovery snapshot. Back and Cancel discard the draft, while a temporary privacy lock preserves it until the user returns. Existing backups remain compatible; no ledger schema change is required.

Install `iou-0.1.0-alpha.10.apk` over the previous alpha. Android version code is `10`; production identity and signing key are unchanged. Search is deferred to a future release at the user's request, and the app remains in alpha until the user confirms the core scope is complete.

TypeScript, 1,354 integrated checks, nine full-app browser scenarios and both GitHub workflows passed. The published APK was independently verified and tested over Alpha 9 on an Android 16 emulator: Cancel/Back, system keyboard, lock/unlock draft preservation and saving passed. An exact backup comparison confirmed unchanged IDs, all transactions, audits, installment allocations and balances, with previous backups and readable exports intact. The user approved the UI preview before publication. Existing compact selector/status-label clipping and remaining cloud-provider/device validation are tracked separately.
