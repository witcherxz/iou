# IoU 0.1 Alpha 1

The first production-signed alpha of **دفتر الديون**: a private Arabic debt ledger in Saudi Riyal. Fresh installations start with an empty book named **دفتري**. Sample people and transactions are kept only in development tests and are excluded from the app bundle.

## Included

- Arabic RTL Material 3 interface, light/dark themes and 0–9 digits.
- Debts, payments, monthly installment plans and actual transaction dates.
- Editing, undo, reversible cancellation and visible correction history.
- Ten local/folder recovery versions, an offline readable report, spreadsheet CSVs and optional password-protected exports.
- Optional biometric/PIN lock and private notification previews.
- Reminder time, advance notices, overdue repetition, weekly day and snoozes.
- Dedicated app icon and visible version in Settings.

## Install

Download **iou-0.1.0-alpha.1.apk** from this release and install it on Android. The APK is a production `release` build, signed with the dedicated IoU release certificate, with debugging disabled. The accompanying `iou-0.1.0-alpha.1.apk.sha256` file lets you verify the downloaded APK.

This alpha uses the production application ID **io.github.witcherxz.iou** and installs separately from the earlier debug app (`com.example.iou`). Existing debug-app records remain in that app. To carry over real records, export a backup there and import it into the alpha. You can remove the old app after verifying the imported records. Future alpha APKs will use the same production ID and signing key.

## Alpha limitations

Biometric hardware, app-switcher privacy, native notification delivery and individual folder providers still need broader device testing. The browser preview cannot verify those behaviors. Ordinary folder/CSV/report exports are readable; password-protected exports use a separate password from the app PIN. Folder synchronization depends on the chosen provider, and direct Google Drive sign-in remains disabled.

Automatic backups run after edits while the app is open. Reminders retain the next 60 debt alerts plus the weekly reminder and refresh on foregrounding. Keep an external backup of important records.

The automated ledger, recovery, encryption, privacy, reminder and UI checks run before GitHub Actions builds the APK. The release process also verifies its package ID, version, signature, non-debuggable manifest, embedded JavaScript and absence of demo fixture content.
