# IoU 0.1 Alpha 9

Person history now labels debt direction simply **يدين لي** or **أدين له**, without the redundant **دين ·** prefix.

Fixed native Arabic text alignment: person names, transaction counts, titles and descriptions now align with the right edge. Native text follows an explicit RTL paragraph, avoiding the mirrored result of forcing `textAlign: right`. Web alignment and explicitly centered controls are preserved. Amount and date inputs keep their existing behavior and 0–9 digits.

Install `iou-0.1.0-alpha.9.apk` over the previous alpha. Version code is `9`, with the same production package and signing key. This is a presentation change; ledger and backup formats are unchanged. The app remains in alpha until the user confirms the core features are complete.

TypeScript and 1,298 integrated checks passed. Four focused browser cases covered light/dark layouts at 320/390 px, Arabic and mixed Latin names, matching right edges for names/counts, descriptions, and no horizontal overflow. The existing 19 history/privacy workflows passed with no browser errors. Alpha 8 reproduced the left-aligned glyphs on the isolated Android 16 emulator despite correct RTL row order; verification of the updated production APK follows the build.
