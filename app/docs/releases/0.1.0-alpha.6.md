# IoU 0.1 Alpha 6

This update removes the embedded number pad from debt and payment/forgiveness forms. Tap the amount field to use your phone's decimal keyboard. Amount validation and 0–9 normalization remain in place.

Android save/restore and password confirmations now stay inside the app window so opening them does not trigger the privacy focus lock. Real background and notification-shade lock rules remain in place. A restore that finishes decrypting after the private dialog host unmounts is cancelled instead of opening a system confirmation while locked.

The Alpha 5 fixes remain included: unfinished entry fields survive adding a person and temporary lock/background transitions, and Android folder backups use provider filenames and owning output streams for verified recovery copies and readable reports. Automatic biometrics and PIN fallback are unchanged.

Install `iou-0.1.0-alpha.6.apk` over the previous alpha. Android version code is `6`; the production package and signing key remain unchanged. Existing records, backup destination, and lock settings are preserved. Verify the APK with its accompanying SHA-256 file.

Before publication, 1,259 integrated checks and TypeScript passed. Eight existing full form-flow scenarios and fourteen settlement, forgiveness, editing, and export scenarios also passed. A held-decryption test reproduced a restore confirmation outside the old lock gate; the updated flow cancels without showing a preview or applying a restore. Eight independent privacy/dialog lifecycle scenarios passed for confirmation, Back handling, queues, real blur/background cancellation, password cleanup, and narrow layouts. Native verification on the isolated Android 16 emulator passed PIN setup/unlock, background draft preservation, actual OS keyboard display, in-window confirmations, local SAF backup, older-snapshot restore, Back cancellation and smaller-file rewrites. Independently verified canonical JSON, all snapshots, readable HTML and CSV agreement. Dropbox-specific provider completion remains unverified.
